# Cryptex-Vault
Cryptex Vault is a secure file encryption and decryption system developed to protect sensitive files using modern cryptographic techniques.

FEATURES:
•Secure file encryption and decryption 
•AES-based encryption usinf fernet 
•Password-based keyb derivation with PBKDF2
•Support for multiple file formats
•User-friendly web interface
•Secure file processing workflow

TECHNOLOGIES USED:
•Python
•Flask
•HTML
•CSS
•Fernet(AES Encryption)

PROJECT OBJECTIVE:
To provide a simple amd secure platform for protecting files from unauthorized access while maintaining usability and performance .

TEAM PROJECT:
This project was developed as a collaboartive academic project focused on cybersecurity and secure file handling concepts.
